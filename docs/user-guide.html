HOW TO USE THIS REPORT

交互说明

这份报告可以筛选比较对象、打开证据、切换场景建议、查看订阅预算并打印。按下面的阅读路线操作即可。

建议先看关键发现，再用能力地图快速定位，最后在矩阵和证据档案中核对细节。点击带蓝色文字或箭头的条目，通常可以继续展开。

1. 推荐阅读路线

  1. 关键发现：先读三条摘要，每条底部的来源编号可以打开支持该结论的原文摘录。
  2. 能力地图：快速浏览五款产品在搜集、引用、改稿、交付四个步骤上的差异。
  3. 竞品对照：筛选你关注的产品和环节，逐个点开单元格查看条件、解释和来源。
  4. 场景选型：选择当前任务，阅读候选产品、推荐理由及试用时要检查的边界。
  5. 订阅与证据：确认套餐口径，复核研究者如何处理资料冲突，并按需搜索原始来源。

2. 能力地图怎么用

地图按“搜集资料、查据、改稿、交付”四步展示五款产品。点击任意产品格，会弹出具体能力说明与证据。点击弹窗中的来源链接可打开原始网页。

下方产品简介中的来源编号同样可点开。地图用于快速定位，不表示质量分数或产品排名。

统一复测任务卡

点击共同任务旁的“查看统一复测任务卡”，可以阅读后续同题测试用的任务提示和记录要求。它是测试方案，不是本报告已执行的产品测试。

3. 竞品矩阵怎么用

筛产品：勾选产品名，矩阵会即时更新。全部取消时会显示提示，可点击“恢复全部产品与环节”。
筛工作环节：点击“搜集资料 / 核对依据 / 写作改稿 / 交付与限制”查看对应维度；选择“全部环节”恢复八项。
看记录：点击单元格打开详情，先读结论与适用条件，再点来源编号看引用原文和访问日期；“查看原始页面”会在新标签打开来源网站。

表格下方显示当前产品数、维度数和记录数。手机屏幕上可在矩阵内横向滚动；焦点落在表格时也可用左右方向键滚动。

4. 场景选型怎么用

点击左侧的场景标签，在资料搜集、整理长材料、反复改稿、交付协作等任务间切换。右侧显示推荐试用候选、判断依据和边界条件。

键盘操作：聚焦一个场景标签后，用 ← / → 或上下方向键切换；Home 到第一个，End 到最后一个。

每项建议代表基于公开资料的试用起点。具体适配情况仍需结合自己的账号入口和任务验证。

5. 价格图与预算计算器

切换计费口径

“按月付款”显示月付方案每月支出；“年付折算 / 月”以年付总额除以 12，旁边明确标出实际需要按年付款。美元与人民币分开绘图，各自使用独立横轴，不能跨币种比较柱长。

查看套餐明细

展开“查看已采集套餐的完整价格与适用口径”，可查套餐名称、月付价格、年付总额、折算月价、地区与来源。套餐图只选了几个有代表性的个人方案，不代表最低价、等量使用额度或完整市场价格。

估算订阅支出

  1. 选一个有月价和年价的套餐。
  2. 拖动月份滑块，设置预计使用 1 至 12 个月。
  3. 比较“月付 × 月数”和“年付一次支付”，读取差额结果。

计算仅比较订阅支出，不含税、优惠、额外用量和退款，也不推算能完成多少份报告。未知年价会保留为空，不按零计算。

6. 证据与研究判断

“核验，怎样改变了结论”列出资料冲突、采用口径和它对选择的影响。产品机会部分按“观察到什么 → 如何判断 → 下一步怎样验证”展开；这是待验证的产品假设。

搜索来源档案

  1. 在“证据档案”搜索框输入产品名、机构名或来源编号，例如 Kimi、O02。
  2. 展开匹配结果，查看发布方、适用范围、访问时间和采集方式。
  3. 阅读原文摘录，或点击来源 URL 打开原始页面。

页面中的“来源与原文摘录”弹窗可以从关键发现、矩阵、价格或场景建议中的来源编号打开。按 Esc 或关闭按钮可关弹窗。

下载数据和任务卡

“下载研究数据”导出本报告使用的 JSON；“下载复测任务卡”保存统一测试提示文本，便于后续执行测试。

7. 打印或保存 PDF

点击报告顶部的“打印 / PDF”，在浏览器打印窗口选择打印机或“另存为 PDF”。打印版会展开全部产品、全部场景、套餐明细和来源内容，适合完整留档。

打印准备会暂时重置产品筛选、价格口径和来源搜索，以保证输出完整；关闭打印窗口后，页面恢复你原来的筛选、计费方式与搜索状态。

8. 状态标签是什么意思

● 有公开说明来源公开描述了该能力；这不代表本项目实测了效果。
◉ 附条件 / 入口差异能力与套餐、入口、地区或设置有关，点击查看具体口径。
▧ 历史二手记录来自注明日期的旧资料，不应直接视为当前承诺。
○ 本次未确认本次查阅的资料没能确认该项；不等于产品不支持。

所有状态同时用文字和符号表达，不依赖颜色辨认。报告是 2026-09-27 的公开资料快照；定价和功能可能变化，购买或实际选型前请打开最新来源核对。
