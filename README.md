# AI 写作助手竞品横评报告

> 对豆包、通义千问、文心一言、Kimi、Claude 五款主流 AI 写作助手做五维度量化横评，输出一份可直接双击打开的可视化调研页面。

---

## ✨ 项目亮点

**🧠 大模型理解**
- 抓住 2026 年产品分化的真实分水岭：**上下文窗口**（128K → 1M → 宣称 1000 万）、**多模态覆盖**（纯文本 → 全模态 + 视频生成）、**Agent 能力**（对话 → OK Computer / Claude Code / MCP）
- 识别出行业级信号：免费额度从"无限"转向"统一额度池 + 冻结"，付费即"变笨"的舆情在豆包与 Anthropic 同时出现
- 指出参数与体验的错位——上下文已卷到 1M–10M，用户反馈仍是"聊着聊着就忘记设定"

**📊 数据分析**
- 5 个竞品 × 5 个评估维度（D1 定位 / D2 模型能力 / D3 定价 / D4 特色功能 / D5 短板），展开为 **15 行对比明细**，全部量化到具体数字
- 定价分档还原：0 元档（文心、豆包）→ 39–68 元档（通义、Kimi、豆包）→ 99–200 元档 → 499–699 元专业档 → Claude $20–$200
- 复用公开行业数据交叉验证：QuestMobile 月活、中国信通院大模型幻觉测试
- 主动标注异常值：文心 5.0 宣称 1000 万 token，与自家 API 主力模型 128K 相差约 78 倍
- **事实性分级**：多来源冲突或官方未公开的数据，经人工复核后以橙色标出（共 5 处），不与已验证数据混淆

**🤖 AI 工具使用**
- 从检索、整理、维度打分到可视化页面产出，全流程由大模型完成
- 用配色可访问性校验工具验证图表配色，因 5 条雷达叠加在红绿色盲模拟下色差 ΔE 仅 1.6（阈值 8），主动改为**小倍数雷达**
- 明确划出 AI 的能力边界：事实性需人工兜底、评分需强制标注主观性

**📋 产品经理竞品分析**
- 不止于"列参数"，直接产出 **5 条可落地的产品机会点**，每条附证据来源与优先级（P0 / P1 / P2）
- 从差评中反推真需求：5 款产品的差评**没有一条指向文笔**，全部指向事实性 → 机会点在"事实可核查"而非"写得更好"
- 每条机会都给出具体产品动作，而非停留在"应该加强 XX"的层面

## 🖼️ 页面预览

深色简约风格，单页滚动，适配作品集演示场景。

- **配色体系**：深色底 `#0d0d0d` + 卡片面 `#1a1a19`，五个产品各占一个固定实体色（豆包蓝 / 通义橙 / 文心青 / Kimi 黄 / Claude 品红），该配色在**整页保持一致**——雷达图、表格色点、柱状图指向同一产品时颜色相同
- **柱状图**：展示免费可用上下文窗口（200K – 10000K），单色相 + 柱顶直接数值标注，避免"文心 10000K 把其他柱子压成 2% 高度"的读数问题
- **雷达图**：5 张小倍数卡片，**3 + 2 两行铺排**，每张单产品五维评分，标题下方显示综合得分
- **对比表**：表头与首列双向吸附，横向滚动时产品列与维度名始终可见
- **橙色标记**：人工复核确认的数据统一使用橙色 `#ec835a`，页脚有图例说明
- **响应式**：1080px / 860px / 560px 三档断点，雷达图逐级降为 2 列、1 列

## 🚀 使用方式

**方式一：本地打开（推荐）**

1. 下载 [`ai-compare-report.html`](ai-compare-report.html)
2. 双击文件，用浏览器打开即可

无需安装依赖、无需构建、无需启动服务。唯一外部依赖为 Chart.js 4.4.1（通过 jsDelivr CDN 加载），**首次打开需联网**。

**方式二：在线预览**

将 HTML 文件放到 GitHub Pages、Vercel 或任何静态托管服务，即可生成分享链接。

## 🔄 工作流程

```
需求定义
   │  确定 5 个竞品、5 个评估维度、输出格式
   ▼
大模型竞品调研
   │  联网检索官方定价页、帮助中心、第三方测评、行业报告
   ▼
生成 Markdown 表格
   │  结构化对比 → 交叉验证 → 标注数据冲突 → 提炼机会点
   ▼
自动构建可视化网页
   │  深色单页 HTML + Chart.js 图表 + 对比表 + 机会分析
   ▼
人工校验与迭代
      复核冲突数据（橙色标记）→ 校验配色可访问性 → 调整布局
```

**流程中的关键取舍**

| 环节 | 决策 | 原因 |
|---|---|---|
| 雷达图形式 | 5 条叠加 → **小倍数** | 叠加时青绿与品红在红绿色盲模拟下色差 ΔE 仅 1.6，低于 8 的可辨阈值 |
| 柱状图配色 | 5 色 → **单色相** | 单一测度下颜色不承载信息，身份已由 X 轴标签承担 |
| 数据可信度 | 全部通过 → **分级标注** | 5 处数据存在多来源冲突或官方未公开，橙色标出以免与已验证数据混淆 |
| 评分来源 | 直接给分 → **标注主观性** | 能力评分为调研主观评估，须说明依据（上下文规格、多模态覆盖、免费额度、公开口碑） |
